- Rates: decided = ต่อแล้ว (signed ≤ cut) + ไม่ต่อ / หลุด with date ≤ cut; past-due open excluded and shown red. Churn colour: decided ≥ 10 → < 15 / 15–19 / ≥ 20 %; < 10 → ≤ 3 / 4 / ≥ 5. Compare: past = previous period, current = cut at today vs same day offset, future = none; Custom = day-level A vs B. Period default = current quarter; back to first data month, forward to today + 12 months; no service / owner filter in the bar.
- Sections: 4 KPI tiles · แยกตาม AE (ORM / Marcom boxes, no totals, no stage colours, divider; red dot = past due, amber = over SLA / waiting reason) · สถานะในช่วงนี้ (urgent tiles: เลยกำหนด + รอบันทึกเหตุผล all periods; ≤ 60 วัน + เกิน SLA by period; board hidden by default, highlight greys non-matches and never hides; clicks in §4 / tiles / search change highlight only, never KPIs / table / reasons) · ทำไมลูกค้าไม่ต่อ / หลุด (top 3 labels pct = n ÷ N; 7 groups count labels, share = ÷ all labels).
- Reasons: `renewal_reasons` browser-local (src/lib/renewal-reasons.ts, demo in-memory; R2.1: pushed to Cloud doc `renewalReasons`); 3 labels from bad labels of groups 1–7; owning AE or PM record any time when missing, edit within RENEWAL_REASON_EDIT_DAYS; others view only; no delete. Old free-text reasons show read-only as หมายเหตุเดิม.
