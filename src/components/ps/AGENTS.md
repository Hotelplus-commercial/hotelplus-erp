## Header R2 (2026-10-28) — supersedes old global period/Compare, All/ORM/Marcom lens, Role/Team/Person filters, 6/7-tile Headline, Portfolio snapshot and header medians
- HR1 Global filter bar: one row ทีม / คน (hierarchical บริการ → ทีม → คน · AE) · ค้นหา · สถานะโรงแรม · Clear All · DEMO. No global period, no global Compare, no All / ORM / Marcom. Clear All does not reset per-card compare choices. Why: time belongs to each card.
- HR2–HR6 Per-card time rule (every chart, every tab): no history → grey chip `ณ วันนี้`, no Δ; history → its own CompareControl เดือน · ไตรมาส · ปี · Custom (A vs B by month), default เดือน, no "no compare". Calendar quarters; unfinished periods compare equal length (to-date vs same span); rebuildable point-in-time values compare as of today vs same day of previous period. One picker per KPI row allowed (Meeting, Task); one per column in the scorecard. Choice persists per user per card (`psdash.cmp.{tab}.{card}`). Known gap: trend charts show only the selected period (one month by default) — redefined in the tab redesign; do not "fix" without a prompt. Why: each card answers its own time question.
- HR7–HR17, HR24, HR25 Customer Journey scorecard: unit = service contract; rows ORM / Marcom × cols 1 รอเริ่ม · 2a ในคิวตอนนี้ · 2b ใช้เวลา Go Live · 3 ใช้งาน · 4 หลุด · 5 คะแนนบริการ · 6 เกรดชำระเงิน. `ณ วันนี้`: 1, 2a, 3 (3 point-in-time by decision); Compare: 2b, 4, 5; col 6 = latest billing cycle, no compare. Mode (ฐานนิยม) for days (2a, 2b) and scores (5), always with `k จาก n`, tie → lower value. Col 2b start = On-board card created date (no AE-accept timestamp exists). Totals `รวม n สัญญา` only in cols 1, 2a, 3, 4 (count only, never combined %); no total row. ทีม / คน: service team → other row dimmed `นอกขอบเขต`, totals hidden except col 1; AE → both rows filtered; col 1 never filtered. Descriptions in ⓘ only; header layers fixed: number → title + ⓘ → chip / picker → total. Why: one explainable per-contract journey.
- HR18–HR22 Active Portfolio: ORM Flat Rate (count + mean fee ฿/month) · Commission (count + simple mean %); Marcom Content (count + delivered/month vs contract quota) · Ads (count + top-up ฿/month) · KOL (count + visits/month vs contract). A contract counts in every group it has; count Δ always grey; every box has its own CompareControl. ORM compare = contracts and prices as of same day of previous period; without a `contract_price_history` row the contract price is used (known gap). Marcom delivery values come only from src/lib/marcom-app-source.ts; until connected show `รอข้อมูลจาก Marcom App`. Why: no fabricated delivery data.
- HR26 Month summary strip "สรุปภาพรวมเดือนนี้": hidden by flag `psdash.monthSummary=false`; its role moves to a future session scorecard zone (good / bad labels → PM / AE create tickets). Not built — do not build or remove without a prompt. Why: avoid two summary surfaces.
